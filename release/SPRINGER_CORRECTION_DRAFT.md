# Draft: note to co-authors about the earlier ICMSLE 2024 paper (not sent)

**Context (facts only).** The code in the repository `Sign_Language_Interpreter` accompanying the Springer paper
"Real-Time Sign Language Interpreter Using MediaPipe, Dynamic Time Warping, and NLP" (ICMSLE 2024,
doi:10.1007/978-981-97-1488-9_7) was largely adapted from the MIT-licensed repository
`gabguerin/Sign-Language-Recognition--MediaPipe-DTW`. The paper does not cite that repository. The repository now carries an
attribution notice, the upstream MIT licence text, citation metadata and honest scope notes (pushed 2026-10-13).
